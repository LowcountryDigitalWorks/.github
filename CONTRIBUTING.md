# Contributing

Lowcountry Digital Works repositories may have project-specific contribution
requirements. Read the repository README, documentation, open pull requests, and
automation before making changes.

For meaningful changes:

1. Create a focused branch.
2. Keep unrelated changes separate.
3. Update documentation and tests with the implementation.
4. Run applicable validation.
5. Open a pull request with scope, impact, checks, and rollback notes.
6. Do not merge consequential changes without explicit approval.

Never commit secrets, customer data, payment data, patient information, or private
account-recovery material.

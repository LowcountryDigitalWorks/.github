# Organization Settings Checklist

Review before treating the organization as production-ready:

- [ ] Business account is a confirmed owner.
- [ ] At least one tested recovery owner exists.
- [ ] Every owner uses MFA and current recovery methods.
- [ ] Default repository visibility is intentional.
- [ ] Repository creation permissions are restricted appropriately.
- [ ] Base permissions follow least privilege.
- [ ] Third-party GitHub Apps are repository-scoped.
- [ ] Secret scanning and dependency alerts are enabled where available.
- [ ] Default branch protections or rulesets are documented.
- [ ] Organization profile and security contact are current.
- [ ] Client repositories do not inherit unnecessary organization-wide access.
- [ ] Owner and app access are reviewed on a recurring schedule.

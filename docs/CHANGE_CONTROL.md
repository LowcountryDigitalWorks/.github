# Change Control

Consequential changes include domain, DNS, email, billing, production deployment,
account ownership, recovery, client-data processing, and security-control changes.

Before execution:

1. Inspect the current state.
2. Record the current value.
3. Describe the proposed value.
4. Identify dependencies and risk.
5. Define validation.
6. Define rollback.
7. Obtain explicit approval.
8. Record the result and any follow-up.

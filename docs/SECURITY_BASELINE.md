# Public Security Baseline

Repositories should use the controls appropriate to their technology:

- MFA for maintainers;
- least-privilege app and collaborator access;
- branch protection or rulesets;
- secret scanning;
- dependency review and update automation;
- build, lint, test, accessibility, and link validation;
- no credentials or production data in source control;
- documented security headers and deployment configuration;
- reproducible rollback.

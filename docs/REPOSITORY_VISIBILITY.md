# Repository Visibility

## Public by default when appropriate

Public repositories are appropriate for company website source, reusable tools,
templates, and non-sensitive documentation.

## Private when required

Use private repositories for:

- client work not explicitly approved for publication;
- internal business operations;
- account and vendor inventories;
- recovery and continuity details;
- contracts, pricing, billing, and financial records;
- private security procedures;
- customer or employee information.

Visibility changes require a review of repository history, issues, artifacts,
Actions logs, releases, and attached files.

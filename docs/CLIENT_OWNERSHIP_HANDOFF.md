# Client Ownership and Handoff

The normal target is client ownership of:

- domain and registrar account;
- DNS and CDN account;
- source repository;
- hosting and deployment project;
- analytics and search properties;
- email and communications systems;
- billing relationships.

Lowcountry Digital Works should receive named access. Handoff must include current
state, permissions, recovery, deployment, rollback, documentation, and removal of
temporary access.

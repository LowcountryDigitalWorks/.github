# Repository Creation Checklist

- [ ] Confirm durable owner: company or client.
- [ ] Choose public or private visibility deliberately.
- [ ] Add a concise README and ownership statement.
- [ ] Define default branch and pull-request process.
- [ ] Add `.gitignore` and secret-handling guidance.
- [ ] Add security and support contacts.
- [ ] Document build, test, deployment, and rollback.
- [ ] Add license only after the intended rights are decided.
- [ ] Configure dependency and secret scanning where applicable.
- [ ] Record third-party integrations and recurring cost.
- [ ] Confirm no shared credentials are required.

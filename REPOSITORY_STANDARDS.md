# Repository Standards

Each maintained repository should define:

- purpose and ownership;
- authoritative branch and release process;
- architecture and dependencies;
- build, test, and deployment instructions;
- security and data-handling expectations;
- rollback and recovery;
- current status and known limitations;
- handoff expectations.

Prefer portable, low-cost, standards-based designs. Avoid unnecessary frameworks,
databases, SaaS products, trackers, and paid dependencies.
